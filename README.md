# Proyecto ORYGN Landing Page - Promotor Independiente

Bienvenido/a al proyecto de la Landing Page para Promotores Independientes de ORYGN. Esta página está diseñada para tener una **alta conversión**, ser moderna, y funcionar como herramienta de captación de ventas y de nuevos promotores.

## Estructura del Proyecto

- `/assets/`: Contiene `css` (hojas de estilo), `js` (scripts lógicos), y `images` (gráficas 3D, mockups de producto, logos).
- `/documents/`: Archivos oficiales descargables, tales como el Plan de Compensación (`ORYGN Comp Plan (ES).pdf`) y la Presentación oficial (`ORYGN Presentation (SP).pdf`).
- `/skills/`: Contiene los lineamientos de diseño, estructura, y metaskills para automatizar procesos o la creación de nuevas skills.
- `/video/`: El video demostrativo de TryGLP y podcasts.
- `index.html`: El código principal de la página (optimizada para Core Web Vitals, HTML Semántico sin inline-styles y Meta/SEO/GEO actualizado).

## Instrucciones para Futuras Sesiones

**IMPORTANTE: ANTES DE REALIZAR CUALQUIER CAMBIO, LEE ESTO.**

1. **Revisa las Skills:** Entra en la carpeta `/skills/` y lee `design_guidelines.prompt` antes de agregar nuevos componentes, colores o cambiar el diseño. Todo el diseño debe mantenerse con la estética "Premium", usando los colores allí especificados (ORYGN Red/Orange & Glassmorphism).
2. **Enlaces Oficiales:** Cualquier enlace de registro o compra en la tienda debe apuntar obligatoriamente a: `https://iorngoldman.orygn.co/`.
3. **Mantenimiento del Copy y SEO:** El copy está optimizado para SEO (intención de búsqueda de "alternativas GLP-1"). Respeta la estructura de etiquetas (H1 único, Open Graph, Schema.org).
4. **Respetar el Diseño Original:** La web es 100% responsive y utiliza CSS nativo con clases utilitarias para evitar lints (cero estilos inline).
5. **Creación de Skills:** Si necesitas estandarizar un nuevo proceso (e.g., SEO, despliegue), usa la skill que permite crear skills leyendo `create_skill.prompt`.
